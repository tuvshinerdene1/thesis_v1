# Educational video game for learning programming & algorithms
A culturally adapted, stylized 3D educational programming environment built for introducing computer science 
concepts, inspired by classic grid-based learning tools and modern low-poly indie aesthetics (such as A Short Hike and Nintendo 3DS titles).

## Project overview
This project modernizes the classic educational programming concept (Kara the Ladybug/Robot) by shifting from a rigid 2D grid to an engaging,
 low-poly 3D isometric environment. Built using the Godot Engine, it features data-driven level generation, a robust step-by-step 
command execution pipeline, and a modular architecture tailored for educational research and usability testing.
